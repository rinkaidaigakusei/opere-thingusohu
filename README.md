# Server Exam Support（サーバ構築演習サポート）

「サーバ構築演習」（AWS の EC2 に LAMP・WordPress・Jupyter を構築する演習）の試験問題を貼り付けると、
**ユーザー名・パスワード・DB名などを読み取って、コピーするだけで使える手順書** を作るWebツールです。

📖 **はじめての人は → [説明書（docs/MANUAL.md）](docs/MANUAL.md)**

> ⚠️ 試験中に使ってよいかは、担当の先生のルールに従ってください。
> コマンドは必ず自分の試験問題と見比べてから実行してください。

## できること

- 📋 **問題文を貼り付けるだけ** で、課題（LAMP / ユーザーディレクトリ / Basic認証 / WordPress / Jupyter / Docker など）と設定値を読み取る
- ✍️ 問題文が無くても、**課題を選んで自分で入力** できる
- ✅ 読み取った値を「抽出済み／要確認／未設定」で表示し、その場で修正できる
- 🧭 **ステップ表示**（1つずつ）と **一覧表示**、**一括実行**（`&&` でまとめて）と **段階実行**（1行ずつ）を切り替え
- 📎 コマンドはボタン1つでコピー。未入力の値があるコマンドはコピーできないので安全
- 🌐 AWS の ssh コマンドを貼ると、手順書の `publicDNS` が本物のアドレスのリンクになる（It works! の確認や phpMyAdmin をクリックで開ける）
- 🖼️ vi の INSERT モードや It works! の画面など、つまずきやすい所は写真つきで説明
- 📝 作業しながら時刻つきでメモ、☑️ 完了チェックと進捗表示

## 使い方（かんたん版）

### Webで使う

下のURLを開くだけです（インストール不要）。

👉 **https://rinkaidaigakusei.github.io/opere-thingusohu/**

### 自分のPCで使う（Windows）

1. 「Code」→「Download ZIP」でダウンロードして展開
2. `start.bat` をダブルクリック（**Python が必要**）
3. ブラウザで `http://127.0.0.1:8755/` が開きます。一緒に開く黒い画面は使い終わるまで閉じないでください

> `index.html` を直接開くと動きません。

### 流れ

```
1. 問題文入力 → 2. 解析結果確認 → 3. 手順書 → 4. 進捗
```

詳しくは [説明書](docs/MANUAL.md) を見てください。

## 安全のために

- 問題文・パスワードは **外部に送信しません**（すべてブラウザの中で処理）
- パスワードなどの値は **保存しません**（保存するのは完了チェックと表示設定だけ）
- このツールは **コマンドを表示・コピーするだけ** で、サーバや AWS を操作しません
